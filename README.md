# 🐋 Advanced Hyperliquid Whale Tracker

Real-time whale position monitoring with smart email alerts, leverage intelligence, and cross-exchange tracking.

## Features

- 🔄 **Live Hyperliquid API** integration
- 📧 **Smart Email Alerts** with cooldown management  
- ⚡ **Leverage Intelligence** & pattern detection
- 🌐 **Cross-Exchange Tracking** across multiple chains
- 📊 **Real-time Dashboard** with historical analytics
- 🎯 **Multi-position strategy** detection

## Deployment

Deployed on Streamlit Cloud: `https://whale-tracker-pro.streamlit.app/`

## Technology Stack

- Python 3.8+
- Streamlit
- Plotly for visualizations
- SQLite for data persistence
- Hyperliquid API
